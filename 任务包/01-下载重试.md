# 任务：给 Rust 下载器的单文件下载函数加失败重试

## 背景

这是一个 Minecraft 启动器的下载模块，8 并发下载游戏资源。当前实现没有任何重试：
网络抖动一次（超时 / 503），整个安装就失败，用户只能重来。

只改写下面这一个函数 `fetch_one`，加上文件级重试。不要动其他代码。

## 现有代码

```rust
pub struct DownloadTask {
    pub url: String,
    pub sha1: String,
    pub path: PathBuf,
    pub size: u64,
}

async fn fetch_one(client: &reqwest::Client, task: &DownloadTask) -> Result<bool, String> {
    if task.path.exists() {
        if task.sha1.is_empty() {
            // 没有 sha1 的任务（Fabric 那些纯 maven 库）只能按「非空文件」判断
            if std::fs::metadata(&task.path)
                .map(|m| m.len() > 0)
                .unwrap_or(false)
            {
                return Ok(false);
            }
        } else if let Some(actual) = sha1_file(&task.path) {
            if actual.eq_ignore_ascii_case(&task.sha1) {
                return Ok(false);
            }
        }
    }

    if let Some(parent) = task.path.parent() {
        tokio::fs::create_dir_all(parent)
            .await
            .map_err(|e| format!("创建目录失败 {parent:?}: {e}"))?;
    }

    let resp = client
        .get(&task.url)
        .send()
        .await
        .map_err(|e| format!("请求失败: {e}"))?;

    if !resp.status().is_success() {
        return Err(format!("HTTP {}", resp.status()));
    }

    let bytes = resp
        .bytes()
        .await
        .map_err(|e| format!("读取响应失败: {e}"))?;

    if !task.sha1.is_empty() {
        let actual = sha1_bytes(&bytes);
        if !actual.eq_ignore_ascii_case(&task.sha1) {
            return Err(format!("SHA1 不匹配（期望 {}，实际 {}）", task.sha1, actual));
        }
    }

    tokio::fs::write(&task.path, &bytes)
        .await
        .map_err(|e| format!("写入失败 {:?}: {e}", task.path))?;

    Ok(true)
}
```

`sha1_file` 和 `sha1_bytes` 已存在，签名分别是：

```rust
pub fn sha1_file(path: &Path) -> Option<String>
pub fn sha1_bytes(bytes: &[u8]) -> String
```

依赖环境：`reqwest 0.12`（rustls-tls）、`tokio 1`（full 特性）、`sha1 0.10`。

## 需求

1. **最多重试 3 次**（含首次共 4 次尝试），指数退避：500ms、1s、2s
2. **区分可重试与不可重试错误**：
   - 可重试：连接错误、超时、HTTP 5xx、HTTP 429
   - 不可重试：HTTP 4xx（429 除外）、SHA1 校验不匹配、本地目录/文件写入失败
3. 不可重试的错误**立即返回**，不要浪费重试次数
4. **函数签名保持不变**：
   `async fn fetch_one(client: &reqwest::Client, task: &DownloadTask) -> Result<bool, String>`
5. **不要引入新依赖**。tokio 已开 full，可直接用 `tokio::time::sleep`
6. 保持原有行为：
   - 文件已存在且 SHA1 命中（或 sha1 为空但文件非空）→ 返回 `Ok(false)`
   - 下载成功 → 返回 `Ok(true)`
7. 最终错误信息要能看出「重试了几次后放弃」以及最后一次的真实原因

## 输出要求

1. 完整的新 `fetch_one` 函数，可直接替换原函数
2. 若新增了辅助函数（如判断错误是否可重试），一并给出完整代码
3. 一小段说明：为什么这样划分可重试 / 不可重试

**只要函数，不要输出整个文件。** 代码必须能通过 `cargo check`。
